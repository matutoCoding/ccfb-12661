# 扩声设计工作室 ADS（Acoustic Design Studio）

浏览器端剧场/会议中心扩声设计工具，对标 EASE 的核心工作流，无需 license、不锁硬件、不依赖任何外部服务。

- **技术栈**：TypeScript 5 + WebGL2（自研渲染器，无 3D 框架依赖）+ Web Audio（卷积试听）+ Web Worker（重计算）+ IndexedDB（本地数据）
- **运行时依赖**：零。仅开发期使用 Vite / Vitest / TypeScript。
- **数据**：项目、场地、方案、材料库、型号库、DSP 预设、干声样本全部存浏览器 IndexedDB，支持 JSON 导出/导入。

## 启动

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建（输出 dist/）
npm run preview    # 预览生产构建
npm test           # 33 个单元/集成测试
npm run typecheck
```

## 声学模型说明（工程近似，非物理仿真）

- **赛宾 RT60**：`RT60 = 0.161·V / Σ(S·α)`，逐倍频程；墙面材料更换即时重算。
- **音箱指向性**：基于水平/垂直 -6dB 覆盖角的二次幂指数偏轴模型，2kHz 以上覆盖角随频率收窄；点声源 6dB/倍距，线阵列单元 3dB/倍距。
- **反射声线**：一阶用虚声源法；二阶对一阶反射线做镜面反射并以接收球（张角约 18°）判定是否覆盖座位，输出路径、延时、各频段级差。回声判据 `Δt > 50ms 且 ΔL > -10dB`（阈值可调）。
- **啸叫余量**：闭合回路（话筒→DSP→音箱→房间→话筒）逐频段算回路增益，余量 = 距离自激的 dB 数；心形话筒指向性按 `0.5(1+cosθ)` 建模。
- **电平预算**：节目源 dBu 起逐级叠加增益/DSP/限幅，最先过载的级标红，末端折算音箱节目声压与最大声压。
- **吊挂校核**：等重箱体算重心，1.25 动态冲击系数，重心偏移按杠杆原理分配不均载，超吊具额定值报警。
- **可听化**：合成 IR = 直达脉冲 + 早期反射（来自声线引擎）+ 逐倍频程指数衰减扩散尾，尾音时间常数 `τ = RT60/ln(1000)`，因此反推 RT60 与赛宾结果一致（测试覆盖，中频 ±25~30%）。试听用 `ConvolverNode` 卷积程序生成的干声（模拟人声/打击/粉噪）。

## Worker 与性能

- `src/workers/`：协议、引擎、Worker 入口、客户端封装。
- 反射路径搜索与啸叫余量、SPL 网格全部在 Worker 跑；客户端新请求自动取消未完成的旧请求（拖动设备不卡界面），Worker 不可用时自动降级主线程。
- 进度消息逐座位回传，UI 显示进度条。

## 目录结构

```
src/
  core/        纯 TS 声学/几何/信号引擎（可独立测试，不碰 DOM）
  workers/     Worker 协议、调度引擎、Worker 入口与客户端
  webgl/       WebGL2 场景渲染器、轨道相机、三维视图
  audio/       Web Audio 卷积试听引擎
  state/       IndexedDB 存储与发布订阅仓库
  ui/          路由、五个页面、可复用组件与样式
```

## 已知简化

- 房间为轴对齐长方体六面墙（剧场/会议厅通用简化），暂不支持斜墙/挑台/楼座。
- 反射最高二阶；散射/扩散用统计混响尾近似，未做束跟踪。
- 空气吸收、线阵列耦合为经验系数；模型用于方案比选与投标出图，不替代正式声学仿真软件的验收级计算。
